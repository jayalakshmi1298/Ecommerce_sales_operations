PROJECT FLOW
1. Use Data > Get Data > From Folder > Combine & Transform for monthly Orders.
2. Clean the combined query.
3. Standardize inconsistent text/case.
4. Handle blanks/nulls and check duplicate/key issues.
5. Merge Orders with Customers on Customer_ID.
6. Merge Orders with Products on Product_ID.
7. Create Month/Year and business calculations.
8. Load the final table.
9. Build PivotTables and PivotCharts.
10. Add slicers and KPI cards.
11. Write business insights.
12. Later add Orders_May_2026.xlsx and test Refresh All.

DASHBOARD KPIs
Total Sales, Total Orders, Total Profit, Profit Margin,
Average Order Value, Return Rate.

CHARTS
Monthly Sales Trend, Sales by Category, Profit by Category,
Top 10 Products, Sales by State, Order Status,
Payment Method, Delivery Performance, Return Reasons.

IMPORTANT
Do not manually clean the raw files. Use Power Query so the process is repeatable.
